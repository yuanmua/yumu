场景对照

场景令牌怎么动
选中列表行standard选中背景从旧行滑到新行，是同一个元素位移，不是两次淡入淡出
切换详情standard旧内容淡出上移 8，新内容淡入从下 8 归位；标题区、侧栏、底栏不动
列表新增 / 删除standard0.96 缩放 + 淡入淡出，其他行让位或合拢
Sheet 进入 / 退出emphasized / standard从上方 −16 下落带轻微过冲；退出反向不过冲
成功反馈emphasized目标元素 1 → 1.04 → 1 一次，配一条 Toast
错误反馈quick变色 + 文字出现。不抖动，不弹窗
运行中状态点2 s 循环不透明度 0.6 ↔ 1，减弱动态时静止
规则
  • 一次只动一个主体。
  • 动效表达因果：右下角按钮触发的 Toast 出现在右下角。
  • 时长不随数量变。100 个实例和 3 个实例的动画一样长。
  • 只改 transform 与 opacity，不动布局。
  • 新动画打断旧动画，不排队。
禁止
  • 抖动、闪烁、弹跳超过一次。
  • 模态进度窗。
  • 背景元素跟着主体一起大幅移动。
  • 动画期间锁住输入。
  • 超过 50 项还做错峰。
状态与渐进披露

高级功能怎么藏，状态怎么给

三层披露：直接可见、一次点击、设置页。默认值永远能用，不做「专家模式」开关。四种状态都要画：空、加载、进度、错误，每一种都要给出下一步动作。

层在哪放什么例子
直接可见页面上90% 用户每次都用的开始游戏、新建、导入、搜索模组
一次点击「···」菜单、右键、折叠区偶尔用、懂的人才用打开文件夹、复制实例、加载器版本、JVM 参数
设置页偏好设置装好后几乎不再碰下载源、代理、Java 列表、强调色

状态

状态怎么做不这么做
加载 < 300 ms什么都不显示闪一下进度环
加载 ≥ 300 ms原位进度环 + 一句话整页遮罩
列表加载骨架 3 行，standard 淡入真实内容空白再突然出现
有进度线性进度条 + 数字，原位模态进度窗
成功emphasized 一次 + Toast弹窗说「成功」
可恢复错误原位红字 + 一个修复按钮弹窗
不可恢复错误系统 alert「出了点问题」+ 翻译后的原因显示原始错误串

文案

这样写
  • 「删除实例」「安装」「开始游戏」
  • 「无法连接 modrinth.com，请检查网络」
  • 「整合包已导入」
  • 「内存越大加载越快，但不要超过物理内存的一半。」
不这样写
  • 「确定」「OK」「是 / 否」
  • 「错误：HTTP 503」
  • 「导入成功！」
  • 「-Xmx4G（JVM 堆上限）」出现在主路径
清单

提 PR 前自查

  1. 这页只有一个强调色按钮吗。
  2. 不改任何默认值能完成任务吗。
  3. 高级项在「···」、折叠区或设置里吗，带后果说明吗。
  4. 空状态、加载、进度、错误四种状态都画了吗，都有下一步动作吗。
  5. 每个状态变化都用了 Bark 动效令牌吗，减弱动态时正常吗。
  6. 尺寸、颜色、间距全部来自令牌吗，没有魔法数字吗。
  7. 三语文案都在 bark/i18n/ 里吗。
  8. 键盘走一遍能完成吗，Esc 和回车对吗。
  9. 深色模式看过了吗。
  10. 和另一端摆在一起，除了字体和窗口边框还有区别吗。

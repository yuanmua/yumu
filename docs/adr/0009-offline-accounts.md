# 0009. 离线账号必须先有微软账号

状态：接受
日期：2026-10-08

## 背景

离线账号绕过正版验证。HMCL、PCL2 直接允许；Modrinth App 完全不支持；Prism 要求先添加至少一个微软账号。

## 决定

跟随 Prism：只有当账号列表里存在至少一个微软账号时，才允许添加离线账号；最后一个微软账号被移除时，离线账号随之删除。核心在 `Accounts::add_offline` 与 `Accounts::remove` 里强制，界面只是把按钮置灰并给出提示。

## 后果

- 单机玩家仍然可以用离线名字进自己的存档，前提是机器上登录过正版账号。
- 命令行与界面行为一致，没有绕过开关。
